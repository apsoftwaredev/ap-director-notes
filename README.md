# Adaptive Philosophy Foundation — Director's Notes (public, redacted)

This repository holds **redacted public summaries** of the nightly Director's Notes for the
Adaptive Philosophy Foundation (Olympia, Washington).

- Each file in `director-notes/` is a short daily summary in Emacs org-mode format.
- Summaries are **redacted** before they are published here: no finances, bank details,
  health, legal matters, private contacts, partner names, or private links.
- The **full entries are private** and are not kept in this repository.
- Every note is reviewed by the Director before it is published.
- New notes start from [`director-notes/TEMPLATE.org`](director-notes/TEMPLATE.org).

Human-directed, AI-assisted: these notes are written with Grok Bot.
